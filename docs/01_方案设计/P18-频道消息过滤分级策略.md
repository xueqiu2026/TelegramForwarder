## 四、技术实现

### 写入方式
通过 PostgreSQL `keywords` 表直接 INSERT。
唯一约束 `(rule_id, keyword, is_regex, is_blacklist)` 防止重复。

### Web UI 兼容性
已验证 `console.py` 有完整的 GET/POST/DELETE `/rules/{id}/keywords` 接口，
写入后可在 Web UI 正常查看、添加、删除。

### 过滤逻辑
`keyword_filter.py` → `check_keywords()` → `process_blacklist_mode()`
- 普通关键词: `keyword.lower() in message_text.lower()` 子串匹配
- 正则关键词: `re.search(keyword, message_text)` 正则匹配
- 匹配到黑名单关键词 → 不转发

## 五、回滚方案

```sql
-- 按 rule_id 批量删除
DELETE FROM keywords WHERE rule_id IN (5, 22, 25, 35, 64, 67, 69, 70);
```
